The project is primarily intended to help new players find useful information and support through the guides, articles, and reports provided by the website.

The official website using this repository is:

https://support.misfitzstatz.com

MisfitzStatz Support is independently operated and is not owned, operated, sponsored, or officially affiliated with Antihero Studios.

## 7. Contributions

Contributions to this repository are handled separately from the general MisfitzStatz contribution rules because this project has specific requirements for support content.

### Every User Is Allowed To

Anyone may submit pull requests for:

- mistakes or errors in existing support pages;
- incorrect or outdated information;
- translation requests or translated pages;
- requests for new support pages; and
- requests to update existing support pages.

Contributions should focus on improving the quality, accuracy, availability, or accessibility of the support project.

### Forbidden Contributions and Activities

Users and contributors must not use this project to:

- search for or exploit loopholes in the project;
- intentionally disrupt the platform or project;
- spread misinformation;
- disclose or leak internal information belonging to Antihero Studios;
- intentionally disrupt the project or its operator;
- represent themselves as official support for Antihero Studios, MisfitzStatz, or Misfitz Support;
- request one-to-one personal support through this project; or
- request or add AI-based support tools to the project.

### Requirements for Contributors

When submitting a pull request, contributors are expected to:

- provide evidence for reported errors or mistakes when requested;
- provide accurate translations for translated pages;
- follow the formatting and structure already used by the project;
- preserve the existing style and organization of support content; and
- ensure that submitted information is accurate to the best of their knowledge.

Evidence for errors or mistakes may be submitted through Discord direct message when the evidence should not be publicly posted.

### Support Content Requests

Requests for new or updated support pages should contain enough information for the requested change to be reviewed.

A contributor does not need to write the complete article themselves.

Requests may identify:

- missing information;
- outdated information;
- errors;
- missing support topics; or
- information that should be updated.

Acceptance and implementation of contributions remain at the discretion of the project operator.
